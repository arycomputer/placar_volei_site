# **App Name**: VolleyCounter

## Core Features:

- Score Tracking: Real-time score tracking for both teams.
- Set Management: Manage sets within a match, track the set number, and record individual set scores.
- Team Details: Record team names and allow for editing before and during the match.
- Undo/Redo Functionality: Allow users to undo or redo actions to correct scoring errors.
- Match Timer: Include a timer to track the duration of sets and the entire match.

## Style Guidelines:

- Primary color: Vibrant Orange (#FF8C00) to evoke energy and excitement, matching the sport's dynamic nature.
- Background color: Light Beige (#F5F5DC), a desaturated variant of orange, to provide a neutral and soft background.
- Accent color: Deep Red (#B22222), analogous to orange, for critical actions and highlights.
- Body and headline font: 'Inter', a sans-serif font for a clean, modern look.
- Use flat, minimalist icons for scoring actions, timer controls, and set management.
- Score should be prominently displayed, while action buttons like 'Undo', 'Redo' should be easily accessible.
- Subtle animations when a point is scored or when transitioning between sets.
